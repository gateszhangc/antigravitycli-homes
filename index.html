Overview

What makes Antigravity CLI the next step

Gemini CLI proved the terminal could be an incredible interface for agentic tasks. Antigravity CLI pours that energy into one product built for multi-agent workflows—with the features you rely on most.

A unified platform, not a fork

Google is concentrating on Google Antigravity—an agent-first development platform with a powerful server-side harness and Antigravity CLI as its terminal front door.

Critical Gemini CLI features preserved

While there won't be 1:1 feature parity on day one, Agent Skills, Hooks, Subagents, and Extensions (now Antigravity plugins) carry forward.

Same jobs, better experience

Whether you used Gemini CLI for grounded answers, scaffolding projects, or provisioning cloud infrastructure—you can still do all of that in Antigravity CLI.

Built for how you work now

Weekly releases, strong terminal UI, and community scale taught Google that your tools must share one backend with desktop, IDE, and cloud workflows.

Timeline

Important dates for consumers & enterprise

Access paths differ depending on whether you use free Gemini Code Assist, paid consumer plans, or enterprise licenses.

For consumers

  • Starting today Antigravity CLI is available to everyone. Begin migrating with official technical documentation and upcoming video walkthroughs.
  • June 18, 2026 Gemini CLI and Gemini Code Assist IDE extensions stop serving requests for Google AI Pro and Ultra, and for free Gemini Code Assist for individuals.
  • GitHub assist On June 18, 2026, no new Gemini Code Assist for GitHub installations on organizations; requests stop in the following weeks.

For enterprise customers

  • Unchanged access Organizations on Gemini Code Assist Standard or Enterprise, or Gemini Code Assist for GitHub through Google Cloud, keep existing access.
  • Continued support Google continues supporting Gemini CLI and Gemini Code Assist with the latest Gemini models and updates for licensed users.
  • Try Antigravity now Enterprise teams can use Antigravity CLI today with Google Cloud projects while evaluating the broader Antigravity platform.
